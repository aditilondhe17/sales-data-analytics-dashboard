# Sales Data Analytics Dashboard

An interactive Sales Data Analytics Dashboard built using Python, Pandas, Streamlit, and Plotly to analyze sales data and visualize business performance.

## Features
- Upload sales data using a CSV file
- Filter data to explore sales information
- View key performance indicators (KPIs)
- Analyze sales by product, region, and month
- Interactive charts and visualizations
- Download filtered data for further analysis

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- CSV

## Installation and Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/aditilondhe17/sales-data-analytics-dashboard.git
   ```

2. Navigate to the project folder:
   ```bash
   cd sales-data-analytics-dashboard
   ```

3. Install the required libraries:
   ```bash
   pip install streamlit pandas plotly
   ```

4. Run the dashboard:
   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.

## Project Goal
To explore sales data, identify trends, compare product and regional performance, and support data-driven decision-making.
